##### **Menu-Driven Bank Account Simulator**



###### **Project Description**

The Menu-Driven Bank Account Simulator is a simple Python project that simulates basic banking operations. It allows users to check their account balance, deposit money, withdraw money, and view their transaction history through a menu-driven interface.



###### **Objective**

The main objective of this project is to practice Python functions, loops, conditional statements, input validation, and state management.



###### **Technologies Used**

\- Programming Language: Python

\- Concepts: Functions, loops, conditional statements, lists, exception handling, and user input



###### **Features**

\- Check Balance: Displays the current account balance.

\- Deposit Money: Adds money to the account after validating the amount.

\- Withdraw Money: Allows withdrawals only when sufficient balance is available.

\- Transaction History: Stores and displays successful deposits and withdrawals.

\- Input Validation: Handles invalid inputs, negative amounts, and incorrect menu choices.

\- Menu-Driven Interface: Continues displaying the menu until the user chooses to exit.



###### **How to Run the Program**

1\. Install Python on your computer.

2\. Copy the program into a file named `bank\_simulator.py`.

3\. Open a terminal or command prompt in the project folder.

4\. Run the following command: python bank\_simulator.py

5\. Select an option from the menu and follow the instructions.



###### **Sample Menu**

===== BANK ACCOUNT SIMULATOR =====

1\. Check Balance

2\. Deposit Money

3\. Withdraw Money

4\. View Transaction History

5\. Exit



###### **Learning Outcomes**

\- Learned how to create and use functions.

\- Practiced loops and conditional statements.

\- Used lists to store transaction history.

\- Applied input validation and exception handling.

\- Learned how to manage an account balance during program execution.



###### **Limitations**

This is a basic simulation for learning purposes. Account information and transaction history are stored temporarily in memory and reset when the program closes.
